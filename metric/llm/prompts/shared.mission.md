WHAT THIS EXERCISE IS

An independent validation team is assessing whether an agentic AI system is fit for the business
purpose it was built for. The validator did not build the agent and does not take the model
owner's testing at face value; it constructs its own scenario space, issues it, and judges what comes
back.

This is the data collection phase. The scenario space defines what evidence will exist, so anything it
fails to provoke is something the validation will never see. Comprehensiveness here is the whole
point. At the same time every scenario is run several times by the model owner, so padding the
scenario space with near-duplicates costs real effort and weakens the challenge by diluting attention
across scenarios that test the same thing.
